# Student Benefits

Free and discounted dev tools, cloud credits, AI platforms and events that help students build, learn and ship, at [student-benefits.github.io](https://student-benefits.github.io). Maintained by automated workflows.

Suggest a [benefit](https://github.com/student-benefits/student-benefits.github.io/issues/new?template=new-benefit.yml) or an [event](https://github.com/student-benefits/student-benefits.github.io/issues/new?template=new-event.yml), or [report a broken one](https://github.com/student-benefits/student-benefits.github.io/issues/new?template=report-broken.yml).

How it works

Grant · GitHub Actions workflows running Claude

The benefits and events lists are kept current by Grant, a set of GitHub Actions workflows. The workflows that change data/ run Claude on a fixed path: Claude writes the change, runs the deterministic check scripts/validate_data.py until it exits 0, then opens a pull request and merges it. No person reviews the change before it merges.

The loop

GenerateClaude writes a change
Verifyvalidate_data.py checks it
pass
MergeClaude opens and merges the PR; the change is live
fail: Claude fixes the change and the check runs again
